# Cellworld VR

## Overview

Multi-agent research environment integrating a dedicated server with Meta Quest 3 clients, built using Unreal Engine 5.3.

---

## System Compatibility

- **Server OS**: Windows 11 (Dedicated Host)
- **Client Device**: Meta Quest 3
- **Engine**: Unreal Engine 5.3.2 (Oculus-VR branch) ([Engine Source](https://github.com/felixmaldonadoos/UnrealEngine#))

---

## Cellworld Server

Make sure to use the [`CellworldServer-dev` branch](https://github.com/felixmaldonadoos/CellworldServer/tree/dev) when working with the server backend.
